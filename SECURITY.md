# Security

agentviz-railway serves the [agentfeed](https://github.com/dmccoystephenson/agentviz)
feed on your own machine and draws it in the browser. What the feed reads and
shows, and how to report a problem, are described in agentviz's
[SECURITY.md](https://github.com/dmccoystephenson/agentviz/blob/main/SECURITY.md).
